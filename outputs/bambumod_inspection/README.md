# Original BambuMod CAD inspection

**Status: reference data.** It describes the original BambuMod housing (Printables 1574762), which has since been replaced on the printer by the [`R8` remix](../BambuMod_Orbiter25_Remix_R8/).

- `cad_inspection.json`: validity and bounding boxes of the two supplied STEP files (`bambumod_remix_and_vent_cover.step`, two solids; `reverses_engineering_ad5m_bambumod.step`, one solid), now kept in [`reference/BambuMod/`](../../reference/BambuMod/). Bounding boxes are file-axis envelopes, not installed dimensions.
- `page_1.png`–`page_3.png`: page images used during the inspection.

The BambuMod model is by Kirill_Wawe, CC BY-NC-SA 4.0.
