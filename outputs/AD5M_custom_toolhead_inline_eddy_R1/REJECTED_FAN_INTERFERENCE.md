# Rejected: stock part-cooling fan interference

User feedback, November 11, 2026: this inline Eddy layout only works without the part-cooling fan and is not worth test-printing. Treat R1 as rejected, not merely untested.

Retaining the stock AD5M part-cooling blower and a working duct is a requirement. The housing/hotend/bracket-only clearance checks did not establish compatibility with the complete fan/duct assembly. Do not recommend printing or installing this revision as a usable toolhead.

A replacement must include the actual part-cooling fan, duct, outlet/air path, hotend fan, carriage rods/belts, wiring and travel clearances before choosing the Eddy position. Inline X alignment is a preference subject to those requirements. Preserve these CAD files only as design history.
