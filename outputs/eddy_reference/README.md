# Eddy reference images

**Status: reference images.**

- `page10.png`: page 10 of the BigTreeTech *Eddy Series User Manual*, showing how to wire the **Eddy Coil** to an EBB36 V1.2 or EBB42 V1.2 over I2C (5V, GND, SCL `PB3`, SDA `PB4`).
- `Eddy_Duo_to_EBB42_official.png`, `official_duo_ebb42.png`: official BTT images of the Eddy Duo / EBB42 connection.

The installed setup does **not** wire the Eddy through the EBB42: the Eddy Duo is its own CAN node (`eddy`, see [`CURRENT_TOOLHEAD_SPEC.md`](../../CURRENT_TOOLHEAD_SPEC.md)). The full manual PDF is in the Google Drive project folder.
